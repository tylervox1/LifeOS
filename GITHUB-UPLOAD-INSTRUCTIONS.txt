LIFEOS GITHUB UPLOAD

1. Create a NEW empty repository on GitHub.
2. Extract this ZIP.
3. Open the extracted LifeOS-GitHub-Repo folder.
4. Upload everything INSIDE that folder to the repository root.
5. Confirm these files are visible at the GitHub repository root:
   - render.yaml
   - package.json
   - Dockerfile
   - README.md
   - START-HERE-RENDER.md
6. Do NOT upload a .env file.
7. After upload, connect the repository to Render using New -> Blueprint.

Important:
- render.yaml must stay at the repository root.
- server/, public/, db/, scripts/, docs/, test/ must remain as folders.
